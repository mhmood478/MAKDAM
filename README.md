# شجرتنا v3
نسخة محسنة لإدارة شجرة العائلة.
- تعديل الشخص.
- حذف الشخص مع إزالة روابط الأب/الأم من الأبناء دون حذف الأبناء.
- إدارة الأب والأم والزوج/الزوجة من شاشة التعديل.
- إضافة قريب حسب نوع العلاقة.
- خطوط الوالدين والأزواج مرتبطة بالبطاقات.
- Firebase Realtime Database.
- databaseURL مضبوط على asia-southeast1.

## مهم
ضع إعدادات Web App الحقيقية في `app.js`.
استبدل الملفات في GitHub بالنسخة الجديدة.
