# Shjartna v5 — clean rebuild

هذه نسخة جديدة من الصفر لمحرك العلاقات.

## أهم قاعدة
لا يتم تحديد موقع الشخص من اسم العلاقة.
البيانات تستخدم:
- `fatherId`: والد الشخص
- `motherId`: والدة الشخص
- `spouseId`: زوج/زوجة الشخص

## سلوك الإضافة
- إضافة أب لأحمد: تحفظ `أحمد.fatherId = ID_الأب`.
- إضافة أم لأحمد: تحفظ `أحمد.motherId = ID_الأم`.
- إضافة أخ/أخت لأحمد: تنسخ fatherId و motherId المعروفين عند أحمد.
- إضافة ابن/ابنة: إذا كان الهدف ذكرًا يصبح fatherId، وإذا كان أنثى يصبح motherId.
- إضافة زوج/زوجة: تحفظ spouseId في الطرفين.

## Firebase
افتح app.js وضع Firebase Web App config الحقيقي.
اترك:
https://shjartna-default-rtdb.asia-southeast1.firebasedatabase.app

لا تنشئ قاعدة جديدة ولا تغيّر المنطقة.

## تجربة مهمة
إذا كانت إعدادات Firebase غير موجودة، ستعمل النسخة في وضع محلي مؤقت حتى تستطيع اختبار المنطق.
لكن لكي تحفظ البيانات بعد إغلاق الصفحة، يجب وضع Firebase config الصحيح.
